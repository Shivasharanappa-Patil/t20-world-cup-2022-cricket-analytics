# 🏏 ICC Men's T20 World Cup 2022 — Cricket Analytics

## 📌 Project Overview

An end-to-end sports analytics project that transforms real-world cricket data from ESPNcricinfo into interactive Power BI dashboards for player performance analysis and Final XI selection.

## 🎯 Business Problem

How can player statistics be analyzed to compare batting and bowling performance, evaluate role-specific strengths, and support the selection of a balanced playing XI?

## 🛠️ Tech Stack

- **Python:** Data cleaning and preparation
- **Pandas & NumPy:** Data manipulation and analysis
- **Power BI:** Interactive dashboards and data visualization
- **Power Query:** Data transformation
- **DAX:** KPI calculations and analytical measures
- **CSV:** Structured datasets

## 🔄 Project Workflow

1. Collected cricket statistics from ESPNcricinfo.
2. Cleaned and prepared the data using Python.
3. Organized player, match, batting, and bowling datasets.
4. Imported and modeled the prepared data in Power BI.
5. Developed interactive dashboards and performance comparisons.
6. Built a Final XI selection dashboard to evaluate player combinations.

## 📊 Dashboard Features

- Player Performance Analysis
- Power Hitters / Openers
- Anchors / Middle Order
- Finishers / Lower Order
- All-Rounders
- Fast Bowlers / Tail End
- Batting and Bowling Analytics
- Interactive Player Comparisons
- Final XI Team Builder

## 📈 Key Metrics

**Batting:** Runs, batting average, strike rate, balls faced, boundary percentage.

**Bowling:** Wickets, economy rate, bowling average, bowling strike rate, dot-ball percentage.

## 📚 Key Learnings

- Real-world data cleaning with Python
- Data preparation and modeling
- Power BI dashboard design
- DAX measures and KPI development
- Interactive data visualization
- Sports performance analysis

## 📎 Data Source

ESPNcricinfo — ICC Men's T20 World Cup 2022 statistics.
